# 🍲 Книга рецептов

**Личная кулинарная книга для домашней кухни.**
Хранит рецепты, пересчитывает порции, собирает список покупок и сама подсказывает, что приготовить.

## ✨ Возможности

| | Что делает | Подробности |
|---|---|---|
| 📖 | **Каталог рецептов** | Категория, порции, время подготовки и готовки, описание, ингредиенты, пошаговое приготовление, заметки; экспорт карточки рецепта в PNG |
| ⭐ | **Оценки и избранное** | Оценка от 1 до 5 звёзд, отметка «в избранное», фильтр «только избранное» |
| 🔍 | **Умный поиск** | По названию и по ингредиентам («что у меня есть из картошки?»), с учётом регистра русских букв |
| 👨‍👩‍👧 | **Состав семьи** | Добавление и переименование участников; архивирование сохраняет их прошлые планы |
| 🧮 | **Пересчёт порций** | Введите нужное число порций, и все количества пересчитаются: `200 г` → `400 г`, `1/2 ч.л.` → `1 ч.л.` |
| 🎲 | **Случайный рецепт** | Когда не знаете, что готовить. Учитывает поиск и фильтры: можно выбрать случайный суп или случайное из избранного |
| 📅 | **Недельный план питания** | Завтрак, обед и ужин на каждый день; отдельный выбор блюда и порций для каждого участника семьи |
| 🛒 | **Список покупок** | Ингредиенты рецепта добавляются одной кнопкой (с нужным числом порций), одинаковые позиции суммируются, купленное отмечается |
| 💾 | **Резервные копии** | Скачивание всех рецептов в один файл и восстановление из него, с защитой от потери данных |
| 🌗 | **Светлая и тёмная тема** | Подстраивается под настройки системы, удобно читается с телефона и планшета на кухне |
| 🔒 | **Всё у вас** | Данные лежат в одном файле на вашем компьютере, ни облаков, ни регистрации, ни слежки |

## 🚀 Быстрый старт

Понадобится только **Python 3.9 или новее** ([скачать](https://www.python.org/downloads/)).
Откройте терминал (в Windows: PowerShell) в папке проекта и выполните:

<table>
<tr>
<td><b>Windows</b></td>
<td><b>macOS / Linux</b></td>
</tr>
<tr>
<td>

```powershell
py -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

</td>
<td>

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

</td>
</tr>
</table>

Браузер откроется сам. Если нет, перейдите на **http://127.0.0.1:5000**.
Остановить программу: `Ctrl+C` в терминале.

> **В следующие разы** достаточно двух команд: активировать окружение (вторая строка) и `python app.py`.
> Всё установленное остаётся в папке `venv`, систему вы не засоряете.

<details>
<summary><b>PowerShell не даёт активировать окружение?</b></summary>

Если Windows пишет, что выполнение скриптов отключено, выполните один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Либо используйте `cmd` и команду `venv\Scripts\activate.bat`.

</details>

## 📅 Недельный план питания

Откройте **«План питания»** в меню. Все дни и поля расписания видны сразу, чтобы заполнять неделю подряд; кнопку **«Увеличить день»** можно использовать для редактирования выбранного дня поверх страницы. Кнопка **«Скачать неделю как PNG»** сохраняет на устройство картинку расписания, которой удобно поделиться или открыть на телефоне. Для каждого активного участника семьи задайте отдельное блюдо и количество порций на завтрак, обед и ужин. Порции по умолчанию равны 1 (допустимо от 1 до 1000). Пустое поле означает, что блюдо ещё не выбрано; вариант **«—»** означает, что этот приём пищи пропускается. Нажмите **«Сохранить план»**, чтобы сохранить неделю в локальной базе. Количество порций сохраняется и переносится вместе с блюдом при копировании недели, а также попадает в JSON-резервную копию. Чтобы использовать эту неделю как шаблон, выберите дату нужной недели и нажмите **«Копировать план»**. Дата автоматически относится к своей календарной неделе; существующий план целевой недели будет полностью заменён после подтверждения.

В разделе **«Состав семьи»** можно добавлять и переименовывать участников. Участника, который больше не должен появляться в новых планах, можно отправить в архив; его записи в старых неделях сохраняются. Архивного участника можно вернуть в состав семьи.

В форме добавления и редактирования рецепта кнопка **«Скачать рецепт как PNG»** сохраняет карточку с текущими полями, включая ещё не сохранённые изменения.

## 🥕 Как вводить ингредиенты

Каждый ингредиент записывается с новой строки: **количество, единица измерения, название**.

```text
200 г мука
2 шт яйцо
1/2 ч.л. соль
1,5 стакана молоко
перец по вкусу
```

| Что написано | Как понимает программа | Пересчитывается |
|---|---|---|
| `200 г мука` | 200 · г · мука | ✅ |
| `1/2 ч.л. соль` | 0,5 · ч.л. · соль | ✅ |
| `1,5 стакана молоко` | 1,5 · стакана · молоко | ✅ |
| `2 яйца` | 2 · (без единицы) · яйца | ✅ |
| `перец по вкусу` | без количества, строка сохраняется как есть | — |

**Распознаваемые единицы:** `г`, `кг`, `мг`, `мл`, `л`, `шт`, `ст.л.`, `ч.л.`, `стакан`, `щепотка`, `зубчик`, `пучок`, `банка`, `упаковка`, `кусок`, `ломтик`, `капля` (и их формы: «стакана», «зубчика» и т. п.).
Дроби можно писать через `/`, десятичные через запятую или точку.

## 🛒 Список покупок

- Откройте рецепт, выберите число порций и нажмите **«Добавить в список покупок»**.
- Одинаковые продукты с одной единицей измерения **суммируются**: `300 г мука` + `200 г мука` = `500 г мука`.
- Добавлять позиции можно и вручную, теми же правилами записи: `500 г картофель`.
- Нажмите на кружок, чтобы отметить купленное. Позиции можно убирать по одной, убирать только купленные или очистить всё.

## 💾 Резервные копии

Раздел **«Резервная копия»** в меню.

**Сохранить.** Кнопка «Скачать копию» отдаёт рецепты, активный и архивный состав семьи и недельные планы питания, включая количество порций для каждого участника, одним читаемым файлом `recipes-backup.json`. Список покупок в JSON-копию не входит.

**Восстановить.** Выберите файл копии и режим:

| Режим | Что происходит |
|---|---|
| **Добавить к текущим** | Рецепты и участники добавляются к вашим; совпадающие имена рецептов пропускаются, участники с совпадающими именами сопоставляются. Записи плана добавляются или заменяют запись с той же датой, приёмом пищи и участником |
| **Заменить всё** | Текущие рецепты, состав семьи и планы питания заменяются данными из файла. Перед этим программа сама сохраняет вашу базу в файл `recipes-before-restore-ГГГГММДД-ЧЧММСС.db`, а браузер просит подтверждение |

**Безопасность.** Восстановление выполняется по принципу «всё или ничего»: если файл повреждён или это не та копия, программа объяснит причину и не изменит данные.

> Список покупок в JSON-копию не входит. Старые JSON-копии в формате только со списком рецептов или с планом на двух участников по-прежнему можно восстановить.
> Можно также просто скопировать файл `recipes.db` (при остановленной программе): это полная копия всей базы, включая планы питания и список покупок.

## 🧩 Устройство проекта

```text
recipe-book/
├── app.py              # сервер, база данных и вся логика
├── requirements.txt    # единственная зависимость: Flask
├── templates/          # страницы (Jinja2)
│   ├── base.html       #   общий каркас и меню
│   ├── index.html      #   список рецептов, поиск, фильтры
│   ├── recipe.html     #   страница рецепта
│   ├── form.html       #   создание и редактирование
│   ├── shopping.html   #   список покупок
│   └── backup.html     #   копирование и восстановление
├── static/
│   └── style.css       # оформление, светлая и тёмная темы
└── recipes.db          # ваша база (появится при первом запуске)
```

**Технологии:** Python · Flask · SQLite (модуль `sqlite3` из стандартной библиотеки) · Jinja2. Никакого JavaScript-фреймворка, внешних шрифтов и CDN: страницы лёгкие и открываются без интернета.

<summary><b>Страницы и адреса</b></summary>

| Адрес | Метод | Назначение |
|---|---|---|

| `/recipe/<id>/shop` | POST | Ингредиенты в список покупок |

| `/shopping` | GET | Список покупок |

## ⚙️ Настройки

В начале файла `app.py`:

```python
HOST, PORT = "127.0.0.1", 5000   # адрес и порт
CATEGORIES = [...]               # список категорий рецептов
UNITS = {...}                    # распознаваемые единицы измерения
```

- Чтобы **добавить свою категорию**, допишите её в `CATEGORIES`.
- Если порт 5000 занят, поменяйте `PORT`, например на `5050`.
- ⚠️ Не меняйте `HOST` на `0.0.0.0`, пока не понимаете последствий: у приложения **нет входа по паролю**, и все в вашей сети смогут читать и менять рецепты. По умолчанию оно доступно только с этого компьютера.

## 🛟 Если что-то не работает

<details>
<summary><b>«Internal Server Error» в браузере</b></summary>

Настоящая причина написана в окне терминала, где запущена программа: найдите последние строки после слова `Traceback`.
Чаще всего помогает остановить программу (`Ctrl+C`) и запустить заново командой `python app.py`. Если в папке лежит пустой или повреждённый `recipes.db` и рецептов в нём нет, удалите его, он создастся заново.

</details>

<details>
<summary><b>«Address already in use» или порт занят</b></summary>

Программа уже запущена в другом окне терминала, или порт занят другим приложением. Закройте лишнее окно или измените `PORT` в `app.py`.

</details>

<details>
<summary><b>Команда <code>python</code> не найдена</b></summary>

В Windows попробуйте `py`, в macOS и Linux `python3`. Если Python не установлен, скачайте его на [python.org](https://www.python.org/downloads/) и при установке в Windows отметьте «Add Python to PATH».

</details>

<details>
<summary><b>Как перенести рецепты на другой компьютер?</b></summary>

Скачайте копию в разделе «Резервная копия» на старом компьютере, установите программу на новом и загрузите файл через «Восстановить».
Или скопируйте файл `recipes.db` в папку проекта на новом компьютере.

</details>

<details>
<summary><b>Можно ли открыть программу с телефона?</b></summary>

По умолчанию нет: она слушает только этот компьютер, и это сделано намеренно ради безопасности (см. раздел «Настройки»). Интерфейс при этом адаптивный и нормально выглядит на узком экране.

</details>
