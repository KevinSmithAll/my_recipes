# Вкусная история

Локальная книга рецептов для домашней кухни. Работает на одном компьютере, данные лежат в файле `recipes.db` рядом с программой. Интернет не нужен.

## Что умеет

- Рецепты: название, категория, порции, время, описание, ингредиенты, шаги, заметки, оценка, избранное.
- Поиск по названию и по ингредиенту (с учётом русского регистра), фильтр по категории и избранному.
- Пересчёт ингредиентов под нужное число порций.
- Список покупок: добавление ингредиентов рецепта одним нажатием (одинаковые позиции суммируются), ручное добавление, отметки о покупке.
- Резервная копия всех рецептов в JSON (пункт «Резервная копия» в меню).

## Запуск

Нужен Python 3.9 или новее ([python.org](https://www.python.org/downloads/)).

Откройте терминал (на Windows: PowerShell) в папке проекта и выполните:

```bash
# 1. Создать виртуальное окружение (один раз)
python -m venv venv

# 2. Активировать его
#    Windows (PowerShell):
venv\Scripts\Activate.ps1
#    Windows (cmd):
venv\Scripts\activate.bat
#    macOS / Linux:
source venv/bin/activate

# 3. Установить зависимости (один раз)
pip install -r requirements.txt

# 4. Запустить
python app.py
```

Браузер откроется сам. Если нет, перейдите на http://127.0.0.1:5000.
Остановить программу: `Ctrl+C` в терминале.

В следующие разы достаточно шагов 2 и 4. На macOS/Linux команда может называться `python3`.

## Как записывать ингредиенты

По одному в строке: **количество, единица, название**.

```
200 г мука
2 шт яйцо
1/2 ч.л. соль
1,5 стакана молоко
перец по вкусу
```

Если строка начинается с числа, программа сможет пересчитывать её при смене порций. Строки без числа («перец по вкусу») остаются как есть.

## Данные и резервные копии

- Вся база: файл `recipes.db`. Чтобы сделать копию или перенести рецепты на другой компьютер, скопируйте его (при остановленной программе).
- «Резервная копия» в меню скачивает все рецепты в читаемом файле `recipes-backup.json`.

## Настройки

Порт и адрес меняются в начале `app.py` (`HOST`, `PORT`). Не меняйте `HOST` на `0.0.0.0`, если не хотите открыть доступ к рецептам всем в вашей сети: у приложения нет входа по паролю.
